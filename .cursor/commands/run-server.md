# run-server

このプロジェクトのビジュアル開発に必要なサーバー群を一括起動するやで！😎✨

## 実行手順

### 一括起動（おすすめ）🚀

```bash
npm run start
```

OSCサーバーとVite開発サーバーが同時に起動するで！

### 別々に起動する場合

1. **OSCサーバーの起動**（OSC受信 + WebSocket + スクリーンショット用HTTP）
   ```bash
   npm run osc-server
   ```

2. **開発サーバーの起動**（Vite）
   ```bash
   npm run dev
   ```

両方のサーバーが立ち上がったら、ブラウザで **`http://localhost:3000`** を開いて開発スタートや！🎉✨

## ポート一覧（この構成が基準）

| 用途 | ポート | メモ |
|------|--------|------|
| **Vite**（アプリ本体） | **3000** | `http://localhost:3000` |
| **OSC受信（UDP）** | **30337** | Max / Processing の送信先 |
| **WebSocket** | **8080** | ブラウザ ↔ osc-server（`ws://127.0.0.1:8080`） |
| **HTTP（スクリーンショット等）** | **3001** | `http://127.0.0.1:3001`（API。`localhost` より IPv4 固定推奨） |

詳細は README のクイックスタートも参照してな！

### MaxからOSC送信する場合

送信先: **`127.0.0.1:30337`** にOSCメッセージを送ればOK！（**`127.0.0.1` 推奨**。`localhost` だけだと環境によってIPv6になり届かんことがあるで）

READMEの「Max/MSP から送信する場合」も併せて見てな！🤔
